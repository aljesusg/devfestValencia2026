# Step 04 — solution notes

There is no extra Go code for this step. Use:

- HTTP server: [`../03-http-transport`](../03-http-transport)
- Cursor config example: [`../../workshop/04-connect-cursor/mcp.json.example`](../../workshop/04-connect-cursor/mcp.json.example)

Copy the example to the repo root as `.cursor/mcp.json` (create the `.cursor` directory if needed):

```bash
cp workshop/04-connect-cursor/mcp.json.example .cursor/mcp.json
```

Start the server, reload MCP in Cursor, then ask about Cloud sessions.
