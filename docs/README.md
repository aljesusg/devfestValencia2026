# Slides

Reveal.js deck for the DevFest Valencia 2026 workshop.

- Local: open `index.html` in a browser, or serve the folder:
  ```bash
  python3 -m http.server -d docs 8000
  ```
- Published: https://aljesusg.github.io/devfestValencia2026/

## Assets

Images under `assets/` are exported from the previous Córdoba deck  
([Google Slides](https://docs.google.com/presentation/d/15z0U7ZZ-aUM66XdRBBLVLAaTE-OPzvDF_oizh-X08Gs/edit?usp=sharing)),
optimized for the web and reused here with DevFest Valencia / English framing.

GitHub Pages is deployed from `docs/` via `.github/workflows/pages.yml`. Enable **Settings → Pages → GitHub Actions** once on the repository.
